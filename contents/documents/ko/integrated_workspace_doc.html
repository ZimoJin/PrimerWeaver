통합 클로닝 작업공간

통합 클로닝 작업공간은 PrimerWeaver의 네 가지 클로닝 워크플로(제한효소 클로닝, Golden Gate 조립, Gibson 조립, USER 클로닝)를 위한 통합 프론트엔드를 제공합니다. 각 개별 모듈에서 벡터와 삽입편 서열을 다시 입력할 필요 없이, 작업공간은 상단에 공유 서열 계층을 유지하고 그 아래에 선택한 방법의 고유한 설계 설정과 출력을 렌더링합니다.

이 작업공간의 용도

이 문서는 작업공간 고유의 통합 계층만 설명합니다. 공유 입력, 방법 전환, 동기화, 상태 유지, 작업공간 수준의 초기화 또는 데모 동작이 해당됩니다. 각 클로닝 방법의 전체 설계 논리를 반복하지 않습니다.

방법별 문서:
  • 제한효소 클로닝
  • Golden Gate 조립
  • Gibson 조립
  • USER 클로닝

빠른 시작 가이드

  1. 상단 입력 영역에 공유 벡터 서열과 삽입편 서열을 붙여넣거나 업로드합니다. 이 필드는 하위 클로닝 모듈과 마찬가지로 FASTA, 일반 텍스트 및 표준 GenBank 텍스트 파일(.gb, .gbk, .gbff, .genbank)을 받습니다.
  2. 클로닝 방법 드롭다운에서 클로닝 방법을 선택합니다. 작업공간은 공유 입력 아래에 해당 방법의 인터페이스를 렌더링합니다.
  3. 렌더링된 모듈 영역에서 방법별 설계 매개변수, 프리셋 및 선택적 고급 설정을 조정한 뒤 평소와 같이 설계를 실행합니다.
  4. 데모 세트는 방법을 선택한 후에만 사용하십시오. 작업공간이 해당 방법 고유의 데모 내용을 공유 영역과 동기화된 방법 창에 불러옵니다.

작업공간 구조

작업공간은 다섯 번째 클로닝 알고리즘이 아니라 공유 셸 어댑터입니다. 공통 서열 입력 영역을 유지하고 그 아래에 선택한 클로닝 모듈을 동적으로 탑재합니다. 한 번에 하나의 방법 창만 활성화되어, 겹치는 요소 ID나 방법별 UI 가정을 사용하는 모듈 간의 DOM 충돌을 방지합니다.

계층 작업공간에서의 역할
공유 상단 입력 클로닝 방법 전반에서 사용되는 공통 벡터 및 삽입편 서열 상태를 보관합니다.
방법 선택기 공유 입력 아래에 렌더링되고 동기화될 클로닝 모듈을 선택합니다.
방법 창 제한효소, Golden Gate, Gibson 또는 USER 클로닝의 고유 인터페이스를 렌더링하되, 작업공간 셸이 이미 제공하는 중복된 최상위 필드는 숨깁니다.
동기화 계층 작업공간 셸과 현재 활성 방법 창 사이에서 공유 벡터/삽입편 상태를 일치시킵니다.

공유 입력과 동기화

상단의 벡터 서열과 삽입편 서열 영역이 작업공간의 기준 입력 필드입니다. 방법을 선택하면 작업공간은 해당 값을 방법별 DOM에 복사하고, 사용자가 내용을 편집할 때 활성 창을 동기화된 상태로 유지합니다.

따라서 모듈마다 동일한 벡터와 삽입편 서열을 다시 붙여넣지 않고도 여러 클로닝 전략을 비교할 수 있습니다. 활성 방법이 동기화된 입력 필드를 수정하면 공유 작업공간 필드도 함께 갱신되어 방법 전환이 일관되게 유지됩니다.

실용적 해석: 작업공간은 공유 서열 입력의 재입력을 줄이도록 설계되었으나, 방법별 가정을 하나의 보편 알고리즘으로 평탄화하지는 않습니다. 최종 해석은 선택한 클로닝 방법과 그 하류 설정, 경고 및 결과에 의존해야 합니다.

방법 전환 동작

클로닝 방법을 전환해도 기본적으로 공유 벡터 및 삽입편 초안은 지워지지 않습니다. 작업공간은 같은 구축 아이디어에 대해 방법을 비교할 수 있도록 해당 서열을 방법 변경 전반에서 유지합니다.

새로 선택한 방법이 이전의 공유 삽입편 패널 해석보다 적은 삽입편을 지원하는 경우, 작업공간은 유효 삽입편 세트를 잘라내기 전에 확인 메시지를 표시합니다. 이를 통해 더 허용적인 조립 방법에서 더 제한적인 방법으로 이동할 때 삽입편 행이 조용히 사라지는 것을 방지합니다.

작업공간 전환 동작 현재 구현
공유 초안 유지 같은 세션 내에서 방법을 전환해도 벡터 및 삽입편 초안이 보존됩니다.
삽입편 용량 불일치 검사 삽입편 용량이 더 낮은 방법으로 전환할 때 삽입편을 삭제하기 전에 작업공간이 경고합니다.
방법별 새로고침 훅 활성 방법 창은 동기화 후 벡터 맵 새로고침과 같은 다시 그리기를 요청할 수 있습니다.

데모 세트와 초기화

작업공간 수준의 데모 세트 버튼은 방법을 인식합니다. 먼저 클로닝 방법을 선택해야 하며, 그렇지 않으면 어떤 모듈의 데모를 불러올지 추측하는 대신 경고를 표시합니다.

작업공간 수준의 초기화 버튼은 로컬 방법 초기화보다 더 강하게 동작합니다. 공유 작업공간 초안을 지우고 페이지를 새로고침하여 셸 상태와 활성 방법 창이 모두 깨끗한 상태로 돌아가도록 합니다.

작업공간 관련 참고 사항

  • 공유 상단 입력 영역은 의도적으로 벡터와 삽입편만으로 단순화되어 있습니다. 방법별 효소, 오버랩, 프라이머 및 매개변수 설정은 아래 방법 창에 남아 있습니다.
  • 하단 방법 창에 표시되는 매개변수 프리셋은 방법별로 고유합니다. 작업공간은 탐색과 공유 서열 입력을 통합하지만, 클로닝 매개변수 프리셋을 하나의 전역 프리셋 형식으로 병합하지는 않습니다.
  • 벡터 맵 동작, 경고 및 결과 해석은 선택한 클로닝 모듈의 책임으로 남습니다.
  • 작업공간은 네 가지 클로닝 도구 위에 구축된 비교 및 조율 계층으로 이해하는 것이 가장 적절하며, 방법 수준 문서를 대체하지 않습니다.
