PrimerWeaver 简介

概述

PrimerWeaver 是面向多种分子生物学工作流程的综合引物设计网络服务器。无论进行限制性内切酶克隆、Golden Gate 组装、Gibson 组装、多重 PCR 还是定点突变，PrimerWeaver 都提供统一平台，简化引物设计与验证。

针对现代分子生物学需求，PrimerWeaver 将智能引物设计算法与稳健的 in silico 质量控制（QC）检查相结合。全部计算均在浏览器中完成（100% 客户端），从而保证数据保持私密。

主要功能

高级质控分析

全面评估引物质量，包括热力学计算、二级结构预测、自身二聚体与交叉二聚体检测。

多重反应分组

使用图着色算法为多重 PCR 自动分组引物，确保各反应池内引物相互兼容。

多种克隆策略

在同一界面中支持重叠延伸 PCR、定点突变、限制性内切酶/连接克隆、USER 克隆、Golden Gate 组装和 Gibson 组装。

100% 客户端计算

不会将数据上传或存储到服务器。引物设计与质控分析均在浏览器本地完成，以最大程度保护隐私。

工作流程概览

典型的 PrimerWeaver 工作流程包括以下步骤：

  1. 选择模块：选择与实验需求相符的克隆或扩增策略。
  2. 输入序列：以 FASTA、纯文本或标准 GenBank（.gb / .gbk / .gbff / .genbank）格式提供靶标序列。PrimerWeaver 支持单片段和多片段组装。
  3. 配置参数：调整目标熔解温度、GC 含量、引物长度及其他策略相关设置。
  4. 设计或验证引物：从头设计新引物，或使用集成质控模块验证现有引物组。
  5. 查看结果：检查详细指标、二级结构、二聚体评分及其他质控指标，以确认引物质量。
  6. 导出并订购：下载引物序列，并向所选寡核苷酸合成供应商下单。

可用模块

引物质控

用于检查任意引物序列质量与兼容性的工具。适合在订购前验证来自文献、既往实验或同事的引物。可计算熔解温度、GC 含量、二级结构及交叉二聚体风险。

重叠延伸 PCR（OE-PCR）

为重叠延伸拼接 PCR（Splicing by Overlap Extension PCR）设计引物。该方法利用互补引物尾将 DNA 片段拼接在一起，适用于两个或多个片段的无缝连接。

定点突变

通过重叠延伸 PCR 设计引物，用于在质粒中引入点突变、插入或缺失。支持多种突变格式，包括氨基酸修饰和 DNA 水平改变。

多重 PCR

为单次 PCR 反应中的多个靶标设计优化引物。包括自动分组，以减少交叉二聚体形成，并确保各反应池中所有引物具有兼容的退火温度。

限制性内切酶克隆

使用特定 II 型内切酶的传统限制性内切酶克隆。选择酶，并设计带有相应识别位点和间隔序列的引物。

USER 克隆

用于非连接依赖组装的 USER（Uracil-Specific Excision Reagent）克隆。自动在引物中引入尿嘧啶残基，以便在 USER 酶切后产生长而特异的突出端。

Golden Gate 组装

基于 IIS 型酶的组装，用于无缝、有序的多部件克隆。支持 BsaI、BsmBI、BbsI 及其他 IIS 型酶。

Gibson 组装

基于重叠的组装，适用于灵活的多片段克隆。为每个片段设计带优化 5′ 同源臂（通常 15–30 bp）的引物，并保持熔解温度一致，以提高组装效率。

为何使用 PrimerWeaver？

集成平台：无需为不同克隆方法在多种工具间切换。所有策略集成于同一界面，并遵循一致的设计原则。
热力学准确：采用统一最近邻热力学模型，并明确支持单价（Na⁺）和二价（Mg²⁺）阳离子，遵循 SantaLucia 等及现代热力学数据库。
面向实验应用：内置质量检查（二级结构、二聚体检测、可靠性评分）有助于引物在实验室中稳定工作，减少失败实验。
隐私优先设计：全部计算均为 100% 客户端完成。序列不会离开您的计算机。无需登录、不使用 cookie、服务器不存储数据。
教学资源：详细文档和逐步说明有助于理解引物设计、热力学和组装策略的原理。

开始使用

要开始设计引物：

  1. 单击顶部导航栏中的“启动应用”。
  2. 在仪表板中选择所需模块。
  3. 上传或粘贴序列并配置参数。
  4. 单击“设计”或“运行 QC”进行分析。
  5. 查看结果并根据需要导出引物。

有关任一模块的更详细信息，请访问主导航菜单中的文档部分。
