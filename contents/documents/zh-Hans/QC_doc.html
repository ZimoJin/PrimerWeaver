引物质控

引物质控功能适用于常规分子生物学工作流程中的多种实际场景。用户可在订购新寡核苷酸之前，对来自文献、数据库或既往实验的引物序列进行验证，并评估现有引物对的兼容性。该模块还能识别可能导致 PCR 失败的引物特征，帮助排查问题并理解某些引物表现不佳的原因。此外，引物质控功能支持比较多个候选引物以辅助优化，也可作为学习资源，帮助理解引物设计的基本原则及影响 PCR 性能的热力学参数。

快速入门指南

  1. 在相应的输入框中上传或粘贴引物序列，并根据需要调整 Na⁺、Mg²⁺、引物浓度和目标 Tm。有关详细的格式要求和参数设置，请参阅下方的详细指南或 QC 模块中的帮助图标。
  2. 单击“运行 QC”按钮执行质量评估。结果将显示在输出区域，其中包括热力学参数、二级结构形成情况和引物对兼容性。

引物质控原理

引物质量控制是 PCR 实验设计和故障排查中的关键环节。高质量引物应能与预期靶标特异性结合，在反应条件下高效退火，并且不易形成非预期的二级结构或引物二聚体。本模块采用最近邻热力学模型、系统化二级结构预测和综合可靠性评分体系，从多个维度评估引物。

主要评估标准

  • 热力学性质：采用统一的最近邻热力学参数，并对 Na⁺ 和 Mg²⁺ 离子进行明确的盐校正，以计算熔解温度（Tm）、GC 含量和 3′ 端稳定性。
  • 二级结构形成：模块可识别并评估单条引物内部的发夹结构及引物对之间的二聚体形成，并通过计算吉布斯自由能（ΔG）评估其稳定性和形成可能性。
  • 引物对兼容性：通过综合多项质量指标的可靠性评分，评估正向和反向引物的交叉二聚体形成、熔解温度匹配程度及总体扩增效率。
  • 序列质量指标：评估同聚物连续序列、3′ 端碱基配对强度及 IUPAC 简并碱基的处理情况，以识别非特异性扩增或特异性降低的潜在原因。

输入格式

支持的序列格式

本模块同时接受多序列 FASTA 和纯文本格式。共享的 MW-22 导入保护机制会阻止上传大于 1 MB 的文件。即使文件低于这一硬性限制，处理超大规模输入时用户界面仍可能变得不稳定，因此仍建议每次运行不超过 500 条序列。系统同时支持标准 DNA 碱基（A、T、G、C）和 IUPAC 简并碱基（R、Y、S、W、K、M、B、D、H、V、N），并将这些碱基纳入互补配对和热力学计算。经用户确认后，规范化过程中将移除非 IUPAC 字符。含简并碱基的引物会在结果中以星号（*）标记。

引物配对识别

本工具可根据灵活的命名约定自动识别引物并进行配对。如果配对存在歧义，报告将标明未配对的引物，并且不执行引物间交叉二聚体检查。支持的命名模式包括：

  • Target1-F / Target1-R（使用连字符）
  • Target1_F / Target1_R（使用下划线）
  • Target1F / Target1R（无分隔符）
  • Target1-Forward / Target1-Reverse（使用完整单词）
  • Target1_Forward / Target1_Reverse（完整单词加下划线）
  • Target1-fwd / Target1-rev（缩写）
  • Target1_FWD / Target1_REV（大写缩写）

QC 参数

运行质量控制分析之前，请检查并调整以下参数，使其与您的 PCR 反应条件相符。

参数 默认值 范围 说明
Na⁺ 浓度（mM） 50 0–200 用于经盐校正的 Tm 计算的单价阳离子浓度。常用范围：10-200 mM。
Mg²⁺ 浓度（mM） 2.0 0–10 用于 Tm 计算的二价阳离子浓度。如果反应中不含 Mg²⁺，请设为 0。常用范围：0.5-5 mM。
引物浓度（nM） 500 50–2000 计算机模拟 Tm 计算所采用的有效引物浓度。常用范围：25-1000 nM。
目标 Tm（°C） 60 40–75 用于评估的目标熔解温度。将受评引物的 Tm 值与此参考值比较，以评估退火兼容性。常用范围：50-65°C。

结果与输出

运行 QC 分析后，模块会生成综合结果，对单条引物性质、引物对兼容性和总体可靠性进行评估。

对于每条引物，工具会显示包含以下内容的综合指标表：

指标 说明
引物 引物名称/标签（如含简并碱基，则以 * 标记）
长度 以核苷酸数表示的引物长度
GC% GC 含量百分比（通常以 40–60% 为最佳）
Tm（Δ） 计算得到的熔解温度及其与目标 Tm 的差值（ΔTm）
3′ 端钳 末端碱基对类型（优选 G/C，A/T 亦可接受）
同聚物 同聚物连续序列检测状态（正常或偏高）
发夹 发夹二级结构分类（无、弱、中等、强）
ΔG（3′ 端 5 bp） 3′ 末端 5 碱基窗口的吉布斯自由能（反映稳定性）
自身二聚体 自身二聚体形成分类及稳定性
交叉二聚体 引物对之间的交叉二聚体形成情况（适用于已配对引物）

可靠性评分

综合多项质量指标计算综合评分（0–100）：

  • 单条引物质量评分（正向和反向引物各占 45% 权重）
  • 交叉二聚体形成评估（扣分或加分）
  • 熔解温度匹配评估（ΔTm > 5°C 时扣分）

评分分类

  • 优秀（≥85）：高质量引物对，可直接用于 PCR
  • 可接受（65–84）：质量良好，仅存在少量问题，通常适用于 PCR
  • 有风险（<65）：检测到明显问题，建议使用前进行复核和优化

预测的二级结构

检测到二聚体或发夹时，工具会提供结构的可视化比对、计算得到的 ΔG 值、分类等级（无、弱、中等、强），以及可能影响 PCR 性能的 3′ 端相互作用警告标记。

计算方法与算法

最近邻热力学模型参数

本工具采用 SantaLucia（1998）和 Allawi & SantaLucia（1997）的统一最近邻（NN）参数，并进行起始校正。对于含 IUPAC 简并碱基的序列，QC 引擎会将每个碱基展开为其所有可能的具体碱基，并采用保守的最不利情况假设：对每个二核苷酸步进，选择在 37 °C 下产生最稳定相互作用（最低 ΔG）的组合，以避免低估结合强度。

最近邻 ΔH°（kcal/mol） ΔS°（cal/mol·K）
AA/TT -7.9 -22.2
AT/TA -7.2 -20.4 / -21.3
CA/TG -8.5 -22.7
GT/AC -8.4 -22.4
CT/AG -7.8 -21.0
GA/TC -8.2 -22.2
CG/GC -10.6 / -9.8 -27.2 / -24.4
GG/CC -8.0 -19.9

熔解温度（Tm）计算

采用统一的最近邻热力学模型，并明确支持单价（Na⁺）和二价（Mg²⁺）阳离子的影响。还会根据下述公式，按照寡核苷酸浓度进一步校正引物熔解温度。

Tm = ΔH° / (ΔS° + R × ln(CT/4)) - 273.15 + 16.6 × log[Na+eq]

其中 Na+eq 包含 Mg2+ 浓度的影响。

GC 含量分析

支持 IUPAC 简并碱基代码，根据下述公式计算 GC 含量百分比，并识别 GC 含量欠佳的引物（通常建议为 40-60%）。

%GC = [Count(G) + Count(C)] / Total Length × 100

二级结构分析

自身二聚体检测

  • 全面扫描潜在的自身二聚体形成
  • 计算二聚体结构的吉布斯自由能（ΔG）
  • 将二聚体分类为：
    • 无：无显著二聚体形成（ΔG > -3 kcal/mol）
    • 弱：稳定性中等（-5 < ΔG ≤ -3 kcal/mol）
    • 中等：稳定性显著（-7 < ΔG ≤ -5 kcal/mol）
    • 强：稳定性高（ΔG ≤ -7 kcal/mol）
  • 特别关注 3′ 端相互作用，因为这类相互作用对 PCR 的影响尤其严重

发夹检测

  • 识别环长度为 3 至 9 个核苷酸的潜在发夹结构
  • 根据 SantaLucia（2004）参数纳入环熵罚值
  • 计算发夹形成的 ΔG，同时考虑：
    • 茎区中的碱基配对
    • 环大小和熵
    • 末端错配
  • 使用与二聚体相同的能量阈值对发夹进行分类

交叉二聚体分析

  • 评估正向和反向引物之间形成二聚体的可能性
  • 对引物对验证至关重要
  • 检测到二聚体结构时提供可视化比对
  • 对可能导致引物二聚体伪影的 3′ 端相互作用发出警告

二聚体扫描算法

  1. 滑动窗口法
    • 检查引物序列之间所有可能的比对方式
    • 同时考虑直接方向和反向互补方向
    • 测试含缺口和突出端的比对
  2. 能量计算：
    • 对匹配区域的最近邻 ΔH° 和 ΔS° 值求和
    • 应用盐校正
    • 考虑末端错配和凸环
  3. 3′ 端相互作用检测：
    • 当二聚体相互作用涉及 3′ 端时予以特别标记
    • 由于延伸从 3′ 末端开始，因此这对 PCR 至关重要

发夹检测算法

  1. 茎区识别：
    • 搜索引物内部的互补区域
    • 最小茎长度：3 个碱基对
    • 允许内部环和凸环
  2. 环熵罚值：
    • 应用取决于环大小的熵罚值：
      • 3-nt 环：+5.7 kcal/mol
      • 4-nt 环：+5.6 kcal/mol
      • 5-nt 环：+4.9 kcal/mol
      • 6-nt 环：+4.4 kcal/mol
      • 7-9-nt 环：+4.5-4.6 kcal/mol
  3. 能量阈值：
    • ΔG ≤ -3 kcal/mol 的发夹被视为显著
    • 更稳定的发夹（ΔG ≤ -7 kcal/mol）将被标记为严重

其他质量指标

3′ 端稳定性（3′ 端钳）

  • 评估 3′ 末端碱基对的稳定性
  • 优选较强的 G/C 端钳，而非 A/T 端钳
  • 由于延伸从 3′ 端开始，因此该指标对 PCR 效率至关重要

同聚物检测

  • 识别相同碱基的连续序列（默认阈值：连续 4 个碱基）
  • 较长的同聚物可能导致滑移和非特异性扩增

IUPAC 简并碱基支持

  • 全面支持歧义 DNA 碱基
  • Tm 和 ΔG 计算采用最稳定（最不利情况）的变体
  • 在结果中以星号（*）明确标记

可靠性评分计算

以 100 分为初始分数，根据各项引物质量指标计算综合评分：

规则 扣分
GC% 超出 40–60%−10
长度超出 18–30 bp−8
无 3′ GC 端钳−5
同聚物（≥4）−8
ΔG（3′ 端 5 bp）≤ −9−10
自身二聚体 = 不良（强/极强）−25
自身二聚体 = 警告（中等）−10
发夹 = 不良−12
发夹 = 警告−6

引物对评分（0–100）

如果两条引物均存在，则按以下公式计算引物对评分：

Scorepair = 0.45 × ScoreF + 0.45 × ScoreR + pp

其中，pp 取决于交叉二聚体分类：

  • 交叉二聚体正常：+10
  • 交叉二聚体警告：−10
  • 交叉二聚体不良：−25

如果 ΔTm > 5 °C，则 pp -= 10。最终分数限制在 [0, 100] 范围内。

警告与边界情况

引物质控模块使用独立的预检警告系统，在分析开始前验证引物列表、配对逻辑、序列规范化和热力学输入范围。模块还会提示若干影响引物对 QC 指标解读的边界情况。

一般警告

这些警告主要在 QC 开始前生成，通常表示输入质量、配对质量或模型适用边界方面存在问题。大多数情况下用户仍可继续，但最终评分或引物对指标的含义可能会发生变化。

类别 触发条件 引物质控模块的当前处理方式
阻断性输入提示 正向和反向引物列表均不含任何可用序列。 模块立即停止，并要求用户提供引物输入后才能运行 QC。
MW-01 / MW-02
仅一侧可用		 解析和清理后，仅正向引物或仅反向引物仍可分析。 模块继续执行单引物 QC；交叉二聚体和引物对可靠性等引物对层级指标不可用。
MW-03
引物数量不匹配		 正向和反向引物条目数量不同。 模块先尝试按名称配对，再回退至按索引配对，因此某些行可能只能作为不完整或未匹配的引物条目进行评估。
MW-04
规范化后无有效序列		 存在引物文本，但规范化后没有有效的 IUPAC 引物。 用户仍可继续，但生成的 QC 输出将为空或缺乏信息价值。
MW-05
已移除非 IUPAC 字符		 一条或多条引物序列含有不支持的字符。 模块仅使用规范化后的序列继续，并警告用于热力学计算的实际序列可能与最初粘贴的文本不同。
MW-06
检测到简并碱基		 一条或多条引物含有歧义 IUPAC 碱基。 热力学数值根据最稳定的解释进行保守估算，因此报告的 Tm 和 ΔG 应视为近似值。
MW-07
引物名称重复		 提交的引物列表中存在重复的引物标签。 模块仍会运行，但配对关系和输出标签可能产生歧义。
MW-08
方向或命名方式疑似异常		 引物标签显示正向引物框中可能存在反向引物、反向引物框中可能存在正向引物，或混用了不兼容的命名方式。 模块会警告自动配对结果可能不符合用户的生物学意图。
MW-09
引物集较大		 引物总数超过 500。 模块会警告浏览器端计算可能变慢或失去响应。
MW-10 至 MW-15
参数范围警告		 Na+、Mg2+、引物浓度或目标 Tm 超出建议或经验证的热力学范围。 模块仍可继续，但在这些条件下，Tm、ΔG 和评分的解读可靠性会降低。
MW-16
结构极其稳定或目标 Tm 极端		 请求的目标 Tm 很高，或一条或多条引物形成非常稳定的自身互补结构。 模块会警告计算结果可能对参数高度敏感，并且实验结果难以解读。
MW-17
引物长度跨度较大		 提交的引物集中，引物长度差异很大。 模块会警告，对于高度异质的引物集合，不同引物间的可比性和评分一致性可能降低。
MW-19
序列总量较大		 规范化后的引物序列总长度非常大。 模块会警告浏览器端 QC 和渲染可能变慢。
MW-21
引物对层级结果大多退化为单引物 QC		 相对于提交的引物列表，可构建的有效正向/反向引物对过少。 模块会警告大多数结果将按单引物 QC 而非真正的成对 QC 进行解读。
MW-22
上传文件超过导入限制		 上传的引物文件大于 1 MB。 导入会在加载序列前被阻止，用户必须选择较小的文件。

设计相关警告

这些边界情况与 QC 结果解读、引物对构建及模块所采用的内部热力学启发式方法有关。

情况 触发条件 引物质控模块的当前处理方式
多序列 FASTA 是预期输入，而非错误 用户以 FASTA 格式提供多条引物。 与单序列模块不同，引物质控专为接受多序列 FASTA 引物列表而设计，因此此处不使用 MW-20。
按名称配对，必要时回退至按索引配对 无法依据命名约定清晰配对引物标签。 模块首先尝试根据推断出的靶标名称和方向匹配引物，再对未解决的条目回退至按索引配对。
单引物行显示的成对信息较少 引物对中的一条引物缺失或不可用。 交叉二聚体和引物对层级指标将显示为不可用，而不会根据不完整数据进行推断。
简并引物会被标记，但仍参与评分 引物含有合法的 IUPAC 歧义代码。 结果表会标记这些引物，并采用保守的热力学假设进行评估，而不会直接拒绝。
发夹和二聚体模型属于启发式模型 在临界能量范围内检测到二级结构。 模块会报告最相关的预测结构，但由于环罚值、凸环和盐效应均为计算近似，湿实验表现可能有所不同。
预设恢复会回退至系统默认值 已保存的 QC 预设格式错误、不完整或无法从本地存储中获取。 模块会恢复内部默认参数，而不会保留无效的预设值。

实际解读：引物质控中的警告并不总是意味着提交的引物不可用。许多警告反映的是序列规范化、配对歧义，或引物对层级 QC 与仅单引物 QC 之间的区别。因此，解读结果时应结合配对状态、交叉二聚体输出和最终评分摘要。
