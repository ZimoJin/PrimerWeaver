定点突变

定点突变模块通过重叠 PCR 引物设计，可在 DNA 模板中精确引入点突变、插入和缺失。该工具支持两种互补的突变策略：编码序列中的蛋白水平突变（自动检测 ORF，并根据宿主生物偏好进行密码子优化），以及对任意基因组区域的 DNA 水平序列编辑。模块会自动设计引物对，通过两步连续 PCR 反应高效组装突变构建体。

快速入门指南

  1. 将含待突变区域的靶 DNA 序列以 FASTA 或纯文本格式上传或粘贴到输入框中。选择 CDS 蛋白突变或 DNA 序列编辑模式。在 CDS 蛋白突变模式下，系统会自动在全部六个读框中检测开放读框（ORF），并默认选择最长 ORF 作为输入；您也可以手动指定所需 ORF。突变可在 CDS 模式中定义为氨基酸替换、插入或缺失，或在 DNA 模式中定义为 DNA 水平的替换、插入或缺失。最后，在继续前根据需要调整设计参数。
  2. 单击“设计引物”以生成诱变引物组。检查设计的引物、质量指标和预测的突变序列。下载 FASTA 格式结果以进行实验验证。

定点突变原理

定点突变是一种分子生物学技术，可向质粒或基因组 DNA 模板中精确引入既定突变。本模块采用的重叠 PCR 策略利用诱变引物引入所需改变，并与侧翼野生型序列重叠，从而通过两轮 PCR 组装出完整突变构建体，无需限制性内切酶或连接反应。

关键设计原则

基于 OE-PCR 的定点突变采用四引物策略，由两条外侧引物和两条诱变引物组成，各自承担不同的热力学和结构作用，以最大限度地提高突变效率：

  • 外侧引物（F1、R2）：定义最终构建体 5′ 和 3′ 边界的野生型侧翼引物。F1 结合于突变位点上游，R2 结合于下游，从而扩增全长突变产物。这些引物可选择携带末端序列（例如限制性酶切位点或亲和标签），用于下游克隆。
  • 诱变引物（Fmut、Rmut）：在其3′ 延伸端引入所需突变的引物，DNA 聚合酶由此起始合成。每条诱变引物都含有野生型侧翼序列以确保特异性结合，并且两条引物在涵盖突变的中心重叠区互为反向互补。该重叠使链延伸和全长突变构建体组装成为可能。
  • 两阶段热力学优化：核心区（含突变的区段）被优化至目标熔解温度（通常为 55–60 °C），以驱动突变片段的初始 PCR 扩增。重叠区（Fmut 与 Rmut 之间的反向互补重叠）用于在延伸 PCR 中支持稳定的引物–引物退火，此时突变 PCR 产物互为引物，从而组装全长构建体。

输入格式

本模块接受FASTA 或纯文本格式的 DNA 序列。每个输入框仅支持一条序列；若检测到多个 FASTA 标题，将仅使用第一条序列。支持两种操作模式：CDS（蛋白突变）和DNA（核苷酸编辑）。

突变定义规则

选定输入序列和突变模式后，突变将按以下坐标和操作规则进行解释。

突变位置为从 1 开始的坐标，并相对于 所选参考序列进行解释：

  • CDS（蛋白突变）模式：位置对应于所选翻译 ORF。
  • DNA 序列编辑模式：位置对应于输入 DNA 序列。

在 CDS 模式中，使用标准单字母符号 * 作为新氨基酸以引入终止密码子（例如 W55*）。单独输入时也接受别名 STOP 和 TER。

两种模式均支持以下操作：

  • 替换 / 置换： 将从 Start 到 End 的序列（或氨基酸） 替换为所提供的新序列。
  • 插入： 将新序列插入指定 Start 位置之后 （End 位置可留空）。
  • 缺失： 删除从 Start 到 End 的序列（或氨基酸）。

如果提供可选的5′ 重叠序列，它们会附加到引物上 用于下游组装，并且不影响突变坐标或 热力学计算。

结果与输出

引物设计完成后，定点突变模块会生成一套完整结果，用于实验验证和下游克隆。模块显示预测的全长突变构建体，展示纳入全部编辑后的完整序列。原始突变位点会突出显示以便查看，序列以 FASTA 格式提供，便于下载并对照目标进行验证。

模块生成四条引物序列：F1（5′ 野生型侧翼引物）、Fmut（含核心区的 5′ 诱变引物）、Rmut（含核心区的 3′ 诱变引物）和 R2（3′ 野生型侧翼引物）。对每条引物，表格显示完整序列（5′→3′）、长度、GC 含量和熔解温度。Tm 值分别报告核心（含突变）区和任何重叠区，以便评估引物结合特异性和扩增兼容性。质量控制指标（包括同聚物连续序列、发夹结构以及自身二聚体/交叉二聚体形成）会被评估并标记，以识别潜在风险。

引物设计算法

ORF 检测与选择

模块会自动在全部六个读框（正向三个，反向链三个）中扫描输入序列，以识别潜在编码序列。对每个读框，ORF 被识别为以 ATG（起始密码子）开始、以 TAA、TAG 或 TGA（终止密码子）结束的序列。所有检测到的 ORF 按长度排序，并预选最长 ORF。如果目标编码序列与检测到的最长读框不同，用户可从排序列表中手动选择其他 ORF。

四引物设计策略

指定突变后，模块按重叠 PCR 策略构建四条引物：

  • F1（正向侧翼）：结合于诱变区域上游（5′）的野生型引物。F1 定义最终 PCR 产物的 5′ 边界，并针对外侧 PCR 扩增进行优化。可选的 5′ 末端序列（例如限制性酶切位点或标签）可附加，且不纳入热力学计算。
  • Rmut（反向诱变）：设计为以核心引物区结合于突变位点紧邻上游（5′）的诱变引物。Rmut 在其 5′ 区（重叠区）中包含部分编辑后序列。
  • Fmut（正向诱变）：设计为以核心引物区结合于突变位点紧邻下游（3′）的诱变引物。Fmut 在其 5′ 区（重叠区）中包含部分编辑后序列。
  • R2（反向侧翼）：结合于诱变区域下游（3′）的野生型引物。R2 定义最终 PCR 产物的 3′ 边界，并可携带可选的 5′ 末端序列（经反向互补），这些序列不参与 Tm 计算。

末端近端编辑的回退策略

默认的四引物 OE-PCR 策略假设突变位点两侧都有足够的野生型序列，以支持两条外侧引物和两条诱变引物。当所请求的编辑过于靠近模板任一末端时，该假设不再成立，因为一侧已无法提供足够长的 PCR 片段以进行稳定扩增。

为处理这种情况，模块会评估编辑位点 5′ 和 3′ 两侧的可用序列长度。如果一侧低于内部最小片段长度要求（约 39 nt），设计会自动切换为单片段 PCR 回退，而不是强制采用标准四引物布局。在该回退模式下，算法将诱变引物保持在编辑区域中心，并仅在仍有足够模板上下文的一侧复用与末端兼容的侧翼引物。

因此，靠近模板起始处的编辑可能产生以 Fmut + R2 为主的设计，而靠近末端的编辑则可能依赖 F1 + Rmut。在极端情况下，如果必须从末端受限的片段直接扩增编辑本身，最终输出实际上可能收缩为单一诱变引物对。这种回退行为是有意为之，反映的是序列末端附近引物放置的物理限制，而不是设计失败。

警告与边界情况

定点突变模块将共享的 MW（Message Warning） 层与突变专用设计回退相结合。部分警告仅为预检，另一些则说明当突变靠近模板末端或序列解释出现歧义时，算法如何改变策略。

一般警告

这些警告主要反映设计前或设计过程中检测到的输入质量或参数质量问题。许多情况下用户可以继续，但由此得到的热力学解释可靠性会降低。

类别 触发条件 定点突变模块的当前处理方式
阻断性输入提示 缺少模板序列、未定义突变/编辑，或所选模式的前提条件无效。 设计立即停止，并要求用户完成所需输入后才能继续有效的突变设计。

设计相关警告

这些边界情况特定于突变算法，尤其涉及 CDS 与 DNA 编辑模式的区别、末端近端突变以及可选末端重叠的使用。

情况 触发条件 定点突变模块的当前处理方式
靠近模板一端的突变 编辑位点过于靠近 5′ 或 3′ 末端，无法留下通常的侧翼片段长度（内部一侧最小约 39 nt）。 模块会自动从默认的四引物重叠 PCR 设计回退到单片段 PCR 策略，因此输出可能只包含一对主要诱变引物，而不是完整的四引物组。
可选末端重叠长度警告 用户提供的正向或反向末端重叠序列超出建议的 15–40 bp 范围。 模块会发出突变专用 MW 提示，但仍允许继续设计，并警告过短的重叠可能降低下游组装效率，而过长的重叠可能增加脱靶配对。
未能可靠检测到 CDS 在 CDS 模式下未自动找到 ORF。 如果清理后的模板足够长，模块会回退使用完整规范化序列作为 CDS 输入；如果过短，设计会停止并要求提供有效的 CDS 模板。
按顺序应用多次编辑 提供了多行突变/编辑。 编辑会按顺序应用，后续每一步设计都使用已被前一步修改的模板。用户输入的位置仍锚定于原始输入/ORF，并映射到每个中间模板；重叠的编辑会因歧义而被拒绝。
CDS 模式的密码子选择行为 蛋白水平替换或插入需要反向翻译为 DNA。 模块使用所选宿主生物的密码子偏好；带有明确选定密码子的单个氨基酸会直接使用该密码子，而多氨基酸编辑则按所选宿主的偏好密码子展开。
重叠/核心构建不足 局部序列上下文不允许在所请求编辑周围形成有效重叠区或足够的核心引物长度。 模块会以设计错误停止，而不是静默生成弱引物组，必须修改突变定义或序列上下文。

实际解读：定点突变中的警告并不一定意味着设计失败。如果编辑过于靠近模板一端，模块可能有意从默认的四引物 OE-PCR 布局回退到单片段 PCR 策略，因此看到少于四条引物可能是预期结果而非错误。最终解读因此应考虑所选模式、突变顺序、可选末端重叠，以及报告结果反映的是默认四引物设计还是末端近端回退策略。
