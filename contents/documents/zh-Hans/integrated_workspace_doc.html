集成克隆工作区

集成克隆工作区为 PrimerWeaver 中的四种克隆流程提供统一前端：限制性内切酶克隆、Golden Gate 组装、Gibson 组装和 USER 克隆。用户无需在各独立模块中反复输入载体和插入片段序列；工作区在顶部保留共享序列层，并在下方呈现所选方法及其专用设计设置与输出。

本工作区的用途

本文仅说明工作区特有的集成层：共享输入、方法切换、同步、状态持久化，以及工作区级重置或演示行为。不会重复各克隆方法的完整设计逻辑。

各方法专用文档：
  • 限制性内切酶克隆
  • Golden Gate 组装
  • Gibson 组装
  • USER 克隆

快速入门指南

  1. 在顶部输入区粘贴或上传共享的载体序列和插入片段序列。这些字段接受 FASTA、纯文本和标准 GenBank 文本文件（.gb、.gbk、.gbff、.genbank），与底层克隆模块相同。
  2. 从克隆方法下拉菜单中选择一种克隆方法。工作区随后会在共享输入下方呈现相应的方法专用界面。
  3. 在呈现的模块区域中调整方法专用设计参数、预设和可选高级设置，然后按常规方式运行设计。
  4. 仅在选择方法后再使用演示数据；工作区会将该方法自带的演示内容加载到共享区域和已同步的方法窗格中。

工作区架构

工作区是共享外壳适配器，而不是第五种克隆算法。它保留一个公共序列输入区，并在其下方动态挂载所选克隆模块。同一时间仅有一个方法窗格处于活动状态，从而避免使用重叠元素 ID 或方法本地界面假设的模块之间发生 DOM 冲突。

层级 在工作区中的作用
共享顶部输入 保存各克隆方法共用的载体和插入片段序列状态。
方法选择器 选择在共享输入下方呈现并同步的克隆模块。
方法窗格 呈现限制性内切酶、Golden Gate、Gibson 或 USER 克隆的原生界面，同时隐藏工作区外壳已提供的重复顶级字段。
同步层 使共享载体/插入片段状态在工作区外壳与当前活动方法窗格之间保持一致。

共享输入与同步

顶部的载体序列和插入片段序列区域是工作区的规范输入字段。选择某种方法后，工作区会将这些值复制到方法专用 DOM 中，并在用户编辑内容时保持活动窗格同步。

因此，用户无需为每个模块手动重新粘贴相同的载体和插入片段序列，即可比较不同克隆策略。如果活动方法修改了已同步的输入字段，共享工作区字段也会更新，从而使方法切换保持一致。

实际解读：工作区旨在减少共享序列输入的重复录入，但不会将所有方法专用假设压平为一种通用算法。最终解读仍应依赖所选克隆方法及其自身的下游设置、警告和结果。

方法切换行为

切换克隆方法时，默认不会清除共享的载体和插入片段草稿。工作区在方法变更过程中保留这些序列，以便用户就同一构建方案比较不同方法。

如果新选择的方法所支持的插入片段数量少于先前对共享插入片段面板的解释，工作区会在截断有效插入片段集之前弹出确认提示。这可避免从较宽松的组装方法切换到较严格的方法时，插入片段行被静默丢失。

工作区切换行为 当前实现
保留共享草稿 在同一会话内切换方法时，载体和插入片段草稿会被保留。
插入片段容量不匹配检查 切换到插入片段容量较低的方法时，工作区会在丢弃插入片段前发出警告。
方法专用刷新钩子 活动方法窗格可在同步后请求重绘，例如刷新载体图谱。

演示数据与重置

工作区级演示数据按钮会识别当前方法。必须先选择克隆方法；否则工作区会显示警告，而不是猜测应加载哪个模块的演示内容。

工作区级重置按钮比局部方法重置更彻底。它会清除共享工作区草稿并刷新页面，使外壳状态和活动方法窗格都恢复为干净状态。

工作区注意事项

  • 共享顶部输入区有意简化为载体加插入片段；方法专用的酶、重叠、引物和参数设置仍保留在下方方法窗格中。
  • 下方方法窗格中显示的参数预设仍为方法专用。工作区统一导航和共享序列输入，但不会将克隆参数预设合并为一种全局预设格式。
  • 载体图谱行为、警告和结果解读仍由所选克隆模块负责。
  • 最好将工作区理解为建立在四种克隆工具之上的比较与编排层，而不是其方法级文档的替代品。
