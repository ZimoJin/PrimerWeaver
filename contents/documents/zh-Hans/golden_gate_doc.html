Golden Gate 组装引物设计器

Golden Gate 组装模块用于设计基于 IIS 型限制性内切酶（通常为 BsaI）和 T4 DNA 连接酶的无疤痕模块化 DNA 组装引物。该工具可自动创建独特的 4 bp 突出端，使多条 DNA 片段能够在单一一锅反应中按确定顺序和方向组装，无需中间纯化步骤。Golden Gate 特别适合标准化生物元件文库、合成生物学应用、高通量遗传回路构建以及迭代设计流程。

快速入门指南

  1. 将目的载体和插入片段序列（最多 6 个片段）以 FASTA 或纯文本格式按所需组装顺序上传或粘贴到相应输入框。选择 Type IIS 酶，核验自动识别的载体骨架，并在必要时调整设计参数。
  2. 单击“设计引物”以生成带有突出端序列的引物。查看引物表、突出端兼容性矩阵和预测组装示意图。下载组装后的 FASTA 文件，确认插入片段方向与预期设计一致。若方向不正确，请将插入片段序列反向互补后重新生成引物。

Golden Gate 组装原理

Golden Gate 组装采用IIS 型限制性内切酶，它们识别特定 DNA 序列但在识别位点之外切割。这一独特性质可产生可预测、可定制的突出端，从而在单一反应中实现多条 DNA 片段的定向、无疤痕连接。关键的是，限制性酶切识别位点在组装过程中被去除，最终构建体中不留下疤痕。

突出端设计原理

Golden Gate 的核心优势在于设计独特、互不干扰的突出端。每个片段对接头需要一个在组装其他位置不存在的独特 4 bp 突出端：

  • 4 bp 突出端：偏移为 1 bp 的 Type IIS 酶（例如 BsaI）天然产生 4 bp 粘性末端，在保持组装简便性的同时提供足够特异性
  • 定向组装：一个片段上的正向突出端必须与相邻片段上的反向突出端互补；非互补突出端无法连接，从而防止错误组装
  • 无疤痕接头：组装后，突出端两侧的 Type IIS 识别位点被去除，从而在片段之间形成无疤痕接头

输入格式

载体和插入片段输入均接受 FASTA、纯 DNA 文本，或带有 LOCUS 和 ORIGIN 区块的标准 GenBank 文件（.gb、.gbk、.gbff、.genbank）。LOCUS 中的短名称用作序列标题。每个输入框只允许一条序列；若检测到多个 FASTA 标题，将仅使用第一条序列。若上传不含 > 标题的纯序列，则使用文件名（不含扩展名）作为名称。专有二进制格式（例如 SnapGene .dna）须先导出为 GenBank 或 FASTA。

PrimerWeaver 目前支持四种内置 Type IIs 限制性内切酶。一旦提供载体序列，系统会自动识别载体特征，并显示所有Type IIs 限制性酶切位点的位置。载体图谱可旋转，以便于查看目标克隆区域。所选载体骨架片段还决定用于第一个插入片段左端和最后一个插入片段右端的自动 4 bp 边界突出端。

片段管理

  • 添加/移除片段：添加多条 DNA 序列用于多片段组装（建议 2–10 个片段；更大组装会更复杂）
  • 重排片段：通过界面控件调整组装顺序；顺序决定最终构建体的结构
  • 片段名称：从 FASTA 标题自动提取，便于引物识别；用于输出报告
  • 反向互补：必要时可切换单个片段，以匹配所需方向和组装方向
  • 内部重叠输入：对于每个内部接头，提供成对的左/右突出端（自定义，4 bp）字段。这两个字段镜像同一接头值。留空可让算法自动选择序列衍生的突出端，或输入恰好 4 bp 的自定义值以覆盖该接头的自动选择。

设计参数

请从下拉列表中选择首选 Type IIs 限制性内切酶，或按酶名搜索。一旦选择限制性内切酶，系统会自动将最长酶切片段识别为默认目的载体骨架。若最长片段并非预期载体骨架，可手动选择另一片段。该骨架选择直接控制分配给第一个和最后一个插入片段末端的自动边界突出端；这些边界值始终取自所选骨架解释，而非手动输入。请在继续前检查引物设计参数，并在必要时修改。

结果与输出

引物设计完成后，Golden Gate 组装模块会生成一套完整结果，便于实验验证和下游克隆。

引物表

设计得到的引物对以结构化表格报告，包括引物序列（5′→3′）、长度、GC 含量和熔解温度（Tm）。Tm 值同时显示退火核心区和全长引物，便于评估扩增兼容性。引物质量指标（包括同聚物连续序列、发卡结构、自二聚体和交叉二聚体形成）会被评估并标记，以突出可能影响 PCR 性能的潜在风险。Type IIS 识别位点和突出端序列在引物序列中突出显示，以便查看。

组装示意图与突出端表

系统会生成组装质粒示意图，说明克隆流程，包括载体线性化、插入片段引入和最终质粒组装。该图提供片段方向和接头结构的概念性概览。重叠区表显示每个接头处的突出端对，确认相邻片段具有互补粘性末端。该表可快速目视核验组装架构是否正确，以及是否存在突出端冲突或不匹配。

模拟琼脂糖凝胶电泳

PrimerWeaver 会生成模拟琼脂糖凝胶图像，以预测关键克隆步骤的实验结果。凝胶包括：

  • 可选 DNA 分子量标准（默认：NEB 1 kb Plus DNA Ladder）
  • 未酶切载体
  • 经 Type IIs 限制性酶切的载体
  • PCR 扩增片段（每个片段一孔，显示预期大小）
  • 组装后的质粒

预测条带大小标注在凝胶旁，便于用户将预期片段大小与实验结果比较，并迅速识别潜在克隆问题。

引物设计算法

引物结构

每条 Golden Gate 引物由三个功能区组成：

  • 退火核心（3′）：驱动 PCR 退火的模板互补区（通常为 18–30 bp）
  • 突出端区（5′）：包含 Type IIS 限制性识别位点和可定制的 4 bp 突出端序列（通常为 11~12 bp）
  • 保护碱基（5′ 侧翼）：限制性位点上游的短碱基，用于提高酶切效率（通常为 2–6 nt；取决于酶）

设计流程

PrimerWeaver 中的 Golden Gate 引物设计分为三个相互衔接的步骤：载体末端解释、接头突出端分配，以及为每个插入片段构建引物尾。这些步骤概述如下。

载体末端解释

载体首先被标准化，并针对所选Type IIS 限制性内切酶扫描。与标准限制性克隆不同，Golden Gate 需要一种载体上下文，使其在 Type IIS 酶切后能够暴露确定的 4 bp 组装突出端。模块计算候选酶切片段，默认自动选择最长片段，并允许用户覆盖该骨架选择。所选骨架片段随后用于从所选 Type IIS 酶的切割几何推导左侧和右侧载体突出端。这些载体衍生值成为第一个插入片段左突出端和最后一个插入片段右突出端的固定边界条件，每当载体/酶/骨架解释改变时，界面会自动覆盖这两个边界字段。

若载体在此解释下不能提供可用的末端突出端，设计不会立即失败。相反，模块记录无法获得载体衍生末端，并在组装边界回退到无疤痕接头规则。

接头突出端分配

载体约束定义后，算法为每个插入片段–插入片段或载体–插入片段接头分配 4 bp 突出端。对于每个内部接头，模块首先检查用户是否在成对的右突出端 / 左突出端字段中输入了自定义接头值。若存在非空自定义值，它必须恰好为 4 bp，并直接用于该接头。若两个成对字段均为空，算法回退到序列衍生候选，通常使用上游插入片段的最后 4 bp和下游插入片段的前 4 bp。这些天然候选会被过滤，以拒绝同聚物 4 聚体或回文 4 聚体等无效 Golden Gate 突出端。

模块随后在组装水平评估完整的接头突出端组合，而不是一次一个接头。只有在考虑反向互补配对后完整面板仍保持唯一时，突出端集合才会被接受。当所选酶有保真度矩阵可用时，PrimerWeaver 按预测连接保真度对有效组合排序，并使用得分最高的兼容集合。若保真度评分不可用，模块回退到第一个有效且无冲突的组合。因此，用户提供的内部 4 bp 接头是全局突出端组合问题的固定约束，而不是装饰性注释。

引物尾构建与组装重建

一旦每个插入片段的左右突出端固定，模块在插入片段末端设计退火核心，然后通过附加 Type IIS 识别位点、间隔碱基和所选 4 bp 突出端作为 5′ 非退火尾来构建完整引物。在此步骤中，PrimerWeaver 去除两个插入片段末端的冗余重叠序列。在左端，它修剪所选 4 bp 突出端与正向退火核心起点之间最大的后缀–前缀重复。在右端，它修剪反向引物核心所覆盖的插入片段序列末端与所选右侧突出端起点之间最大的重复。例如，若自定义左突出端以 ATG 结尾且插入片段核心已以 ATG 开始，或插入片段已以 AATG 结尾且所选右突出端以 AATG 开始，则共享序列不会在最终引物尾中重复。因此完整 Golden Gate 引物遵循此结构：

5′ 保护夹 + Type IIS 位点 + 偏移碱基 + 所选 4 bp 突出端 + 退火核心 3′

引物构建后，模块根据推导的载体切割位置和所选接头突出端逻辑，将酶切后的载体骨架与插入片段块组合，重建组装质粒。当载体衍生末端可用时，骨架从 Type IIS 切割位置重新提取，并用作组装序列重建的物理骨架。否则，模块回退到更简单的无疤痕拼接模型，用于报告组装序列长度和下游可视化。

算法中的边界情况逻辑

算法边界情况 Golden Gate 模块的当前行为
载体有零个或一个 Type IIS 位点 模块不尝试正常的 Golden Gate 骨架解释。相反，它报告 N/A 式组装输出，因为载体无法提供标准 Golden Gate 组装所需的双侧 Type IIS 酶切上下文。
无法干净地恢复载体衍生末端突出端 若无法推导显式载体末端突出端，算法在第一和最后一个接头回退到无疤痕边界规则，而不是立即放弃整个设计。
用户手动提供内部 4 bp 接头 非空的内部自定义突出端被视为固定接头选择。成对的左/右界面字段镜像同一接头值，全局突出端搜索必须容纳该预先选定的 4 bp 约束。
内部自定义接头仅部分填写 若内部重叠字段非空但不是恰好 4 bp，模块会用警告对话框阻止设计，而不是静默猜测或补齐接头。
无法独立选择任何一个接头突出端 算法在完整组装面板上评估突出端组合，因为局部可接受的突出端仍可能与构建体其他位置的另一接头或其反向互补冲突。
保真度矩阵不可用 模块仍通过回退到第一个有效且无冲突的突出端组合来完成设计，但无法再按预测连接保真度对组合排序。
所选突出端已存在于插入片段末端 在引物构建期间，模块检查所选 4 bp 突出端与引物核心已覆盖的插入片段序列之间的最大共享重叠。这在左边界和右边界都进行评估，因此即使 4 bp 突出端仅有一部分已存在于插入片段起点或终点，共享序列也不会重复。
插入片段内部存在 Type IIS 位点 算法仍可构建引物，但设计会被标记，因为内部酶切位点可能在酶切过程中将插入片段切断，从而破坏预期的 Golden Gate 组装拓扑。
片段顺序改变完整突出端解 由于接头突出端从相邻片段序列上下文分配，重排插入片段不仅改变一个接头，也改变全局突出端组合问题，并可能产生不同的最终引物集。

警告与边界情况

Golden Gate 组装模块在公共可视化层可用时，使用共享的 MW（Message Warning）框架进行预检验证和确认对话框。一些警告出现在设计开始之前，另一些仅在模块检查载体拓扑、Type IIS 位点和候选突出端组合之后才被解释。

一般警告

这些警告大多来自共享输入验证和高层 Golden Gate 预检。在大多数情况下，用户可单击Cancel以修改设置，或单击OK继续。

设计警告

这些警告和边界情况针对 Golden Gate 设计算法和输出解释。

情况 触发条件 GGA 模块的当前行为
插入片段数量上限 尝试添加超过六行插入片段。 当前实现将 Golden Gate 设计限制为六个插入片段。一旦存在六个插入片段，界面会禁用进一步添加，内部收集逻辑也会截断为前六个非空插入片段。
载体中所选 Type IIS 位点少于两个 所选载体对所选酶含有零个或一个位点。 模块不产生完整 Golden Gate 组装设计。输出渲染为 N/A，凝胶模型仅显示未切割载体或单切线性化载体。
自动骨架选择 载体含有多个酶切片段。 模块自动使用最长酶切片段作为候选骨架，并提供片段选择器以便用户核验或覆盖该选择。更改所选骨架也会重新计算自动的第一/最后一个插入片段突出端。
边界突出端字段不可由用户编辑 第一个插入片段左突出端和最后一个插入片段右突出端是从所选载体骨架推导的边界条件。 这两个字段显示为自动填充的只读值。若载体序列、酶或骨架选择改变，模块会用新推导的边界突出端覆盖它们。
载体末端突出端不可恢复 模块无法可靠地在所选载体末端推导 Type IIS 突出端。 设计在载体边界回退到更通用的无疤痕规则策略，使用片段衍生末端序列而不是载体衍生突出端约束。
除非手动固定，内部接头突出端受候选限制 若内部接头留空，算法只考虑两个天然候选：上游插入片段的最后 4 bp或下游插入片段的前 4 bp。若用户提供自定义 4 bp 内部重叠，该手动选择会替换该接头的天然候选搜索。 这使默认设计保持疤痕最小且源自序列，同时仍允许用户在克隆标准或元件文库要求时固定特定的内部 4 bp 接头。
拒绝同聚物 / 回文 4 聚体 候选突出端是 4 bp 同聚物或 4 bp 回文。 该候选被排除在有效突出端组合之外，因为它更容易发生错误连接或歧义。
未找到有效的唯一接头集合 没有突出端组合能与反向互补一起通过唯一性过滤，或保真度优化无法识别有效的首选集合。 算法回退到每个接头的默认候选选择，因此即使突出端集合次优，仍可能产生设计。
保真度评分不可用 无法为所选酶 / 接头集合加载或计算连接保真度矩阵。 设计仍继续，但保真度面板可能缺失，突出端集合在没有最终基于矩阵的排序下被选择。
第一 / 最后一个突出端回退 载体衍生末端约束不可用。 第一个插入片段左突出端回退到插入片段 #1 的 5′ 端，最后一个插入片段右突出端回退到末端插入片段的 3′ 端。
插入片段内部酶切位点 所选 Type IIS 酶在一个或多个插入片段序列内部切割。 显示警告，因为即使仍可生成引物，这些插入片段也可能在 Golden Gate 反应中被切断。
组装示意图为示意 任何成功的多片段设计。 组装图像是概念示意图，而非长度精确的质粒图；用户应依赖序列输出和突出端表进行精确解释。

实际解读：在 Golden Gate 组装中，警告往往反映拓扑或突出端质量，而不是完全的设计失败。用户应将警告与骨架选择器、突出端表、可选的保真度部分以及最终组装序列一并解读。
