USER 酶克隆引物设计器

USER 克隆模块用于设计基于 USER 酶系统（Uracil-Specific Excision Reagent）的定向 DNA 组装引物。该工具可自动在引物的指定位置引入尿嘧啶碱基，这些碱基在室温下被 USER 酶识别并切割，从而产生相容的粘性末端。USER 克隆将限制性内切酶克隆的简便性与定向控制，与无疤痕组装方法的灵活性和效率相结合，为多片段或载体–插入片段克隆提供快速的单管替代方案。

快速入门指南

  1. 将目的载体和插入片段序列（最多 3 个片段）以 FASTA 或纯文本格式按所需组装顺序上传或粘贴到相应输入框。提供载体线性化所用的 PCR 引物；含尿嘧啶的引物会自动检测，以用于 USER 兼容设计。核验自动识别的载体骨架，并在必要时调整设计参数。
  2. 单击“设计引物”以生成带有突出端序列的引物。查看引物表、重叠区表和预测组装示意图。下载组装后的 FASTA 文件，确认插入片段方向与预期设计一致。若方向不正确，请将插入片段序列反向互补后重新生成引物。

USER 酶克隆原理

USER（Uracil-Specific Excision Reagent）克隆是一种定向 DNA 组装方法，利用引物中引入的尿嘧啶（U）残基的位点特异性去除。在指定位置引入的尿嘧啶碱基由尿嘧啶 DNA 糖苷酶（UDG）切除，产生无碱基位点，随后由核酸内切酶 VIII切割，从而在片段末端形成互补的单链突出端。这些突出端使 DNA 片段能够精确、定向地退火，而最终的缺口修复和链封闭通常由转化后宿主细胞的 DNA 修复机制完成，无需体外连接。

重叠区设计原理

USER 克隆的成功取决于设计短的、接头特异性的重叠区，这些重叠区在含尿嘧啶的引物延伸经 USER 处理后被暴露。在每个片段接头处，需要一对匹配的互补突出端，以确保定向组装以及转化后的无疤痕修复。

  • 互补突出端：对于每个接头，引物的设计使 USER 处理后在相邻片段末端暴露互补的单链突出端。只有正确匹配的突出端才能退火，从而强制实现预期的片段顺序和方向。
  • 最佳突出端长度：USER 突出端通常为 7–15 个核苷酸，为定向组装提供足够的特异性和退火稳定性。在多片段设计中，各接头的突出端应互不相同，以避免交叉退火和错误组装。
  • 无疤痕接头：由于突出端在 USER 处理过程中被去除，且不保留限制性酶切位点，组装后的片段连接时不会引入额外序列。最终的缺口修复和链封闭在体内完成，从而形成无疤痕接头。

输入格式

载体和插入片段输入均接受 FASTA、纯 DNA 文本，或带有 LOCUS 和 ORIGIN 区块的标准 GenBank 文件（.gb、.gbk、.gbff、.genbank）。LOCUS 中的短名称用作序列标题。每个输入框只允许一条序列；若检测到多个 FASTA 标题，将仅使用第一条序列。若上传不含 > 标题的纯序列，则使用文件名（不含扩展名）作为名称。专有二进制格式（例如 SnapGene .dna）须先导出为 GenBank 或 FASTA。FASTA 或 GenBank 中的片段名称在适用时用于引物命名。

一旦提供载体序列，系统会自动识别载体特征。载体图谱可旋转，以便于查看目标克隆区域。

片段管理

  • 添加/移除片段：添加多条 DNA 序列用于多片段组装（建议 2–10 个片段；更大组装会更复杂）
  • 重排片段：通过界面控件调整组装顺序；顺序决定最终构建体的结构
  • 片段名称：从 FASTA 标题自动提取，便于引物识别；用于输出报告
  • 反向互补：必要时可切换单个片段，以匹配所需方向和组装方向

结果与输出

引物设计完成后，USER 克隆模块会生成一套完整结果，便于实验验证和下游克隆。

引物表

设计得到的引物对以结构化表格呈现，包含完整引物序列信息（5′→3′）、长度、GC 含量和熔解温度（Tm）。Tm 值同时显示退火核心区和全长引物，便于评估扩增兼容性。引物质量指标（包括同聚物连续序列、发卡结构、自二聚体和交叉二聚体形成）会被评估并标记，以突出可能影响 PCR 性能的潜在风险。引物序列中的重叠区以粗体突出显示，便于查看。

组装示意图与突出端表

系统会生成组装质粒示意图，说明克隆流程，包括载体线性化、插入片段引入和最终质粒组装。该图提供片段方向和接头结构的概念性概览。重叠区表显示每个接头处的重叠序列，确认相邻片段具有互补同源区。该表可快速目视核验组装架构是否正确，以及是否存在突出端冲突或不匹配。

注意：组装示意图仅为示意，未按比例绘制。精确解释应以组装序列和接头重叠信息为依据。

模拟琼脂糖凝胶电泳

PrimerWeaver 会生成模拟琼脂糖凝胶图像，以预测关键克隆步骤的实验结果。凝胶包括：

  • 可选 DNA 分子量标准（默认：NEB 1 kb Plus DNA Ladder）
  • 未酶切载体
  • 经 PCR 线性化的载体
  • PCR 扩增片段（每个片段一孔，显示含重叠区的预期大小）
  • USER 克隆产物（显示组装后的构建体）

预测条带大小已标注，便于与实验结果快速比较，并迅速识别酶切效率或组装问题。

引物设计算法

引物结构

每条 USER 克隆引物由三个功能区组成：

  • 退火核心（3′）：驱动 PCR 退火的模板互补区（通常为 18–30 bp）
  • 尿嘧啶标记：位于 USER 化学所用指定切割位置的单个 U。
  • 重叠区（5′）：接头特异性序列，USER 处理后成为暴露的粘性末端（通常在用户定义的重叠范围内）。

设计流程

PrimerWeaver 中的正式 USER 流程假定两条载体线性化引物已作为含 U 的 USER 引物提供。在此假定下，算法最好理解为四个阶段：重建 PCR 线性化载体、从所提供引物推导面向载体的 USER 接头、发现插入片段之间的内部 USER 兼容接头，然后围绕这些固定的 USER 尾部构建最终插入片段引物。

阶段 1. 从 USER 引物重建 PCR 线性化载体产物

模块首先在末端 U处解析每条载体引物。该 U 之前的序列被视为定义 USER 重叠的区段，该 U 之后的序列被视为用于将引物映射回载体的 3′ 核心。利用这些 U 后核心区，代码重建 PCR 线性化载体产物。若直接映射失败，仍会在中止前尝试反向互补 / 引物对调解释。保留的 PCR 产物成为后续所有 USER 接头计算所用的载体骨架。

阶段 2. 定义面向载体的 USER 边界

一旦 PCR 产物确定，载体侧 USER 接头直接从用户提供的载体引物推导，而非从零发明。实际上，每条载体引物中末端 U 之前的序列定义了载体边界处预期的粘性末端逻辑，面向插入片段的引物尾部则生成以在切割后匹配这些 USER 边界。这意味着所提供的载体引物不仅是验证输入，也是最终克隆几何的主动边界约束。

阶段 3. 在内部插入片段–插入片段接头处搜索 USER 兼容重叠基序

对于相邻插入片段之间的每个内部接头，PrimerWeaver 在该接头附近的插入片段组装中搜索形式为 A + N{4-13} + T 的 USER 兼容基序。候选基序按它们在预期接头上的位置、重叠长度与请求设置的接近程度，以及重叠 Tm 与目标重叠行为的接近程度排序。一旦选定合适基序，末端切割位置的 T 会在设计的引物尾部中转换为 U，从而使 USER 处理暴露预期的粘性末端。

阶段 4. 设计模板结合核心并构建完整 USER 引物

每个 USER 尾部固定后，模块从接头向外延伸以设计 3′ 核心结合区。核心长度在有界窗口内扫描，并按计算得到的盐校正 Tm 与目标 Tm 之差评分，因此算法选择最接近的可用核心，而不是简单地选择通过阈值的最短核心。最终引物随后组装为5′ USER 尾部（含 U 切割标记）+ 3′ 模板结合核心。载体引物大体保留用户输入，而插入片段引物的生成使 USER 处理在整个组装中产生预期的相容末端。

算法中的边界情况逻辑

算法边界情况 USER 模块的当前行为

警告与边界情况

USER 克隆模块将共享的 MW（Message Warning）检查与围绕含尿嘧啶引物、重叠区发现，以及在找不到规范 USER 兼容接头模式时的行为的 USER 专用验证相结合。

一般警告

这些警告大多出现在最终设计生成之前，反映序列质量或参数质量问题。
