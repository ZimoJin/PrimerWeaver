# Localization review status

The French, Korean, and 中文 copy in this pilot is an AI-assisted draft. It must receive human scientific and native-language review before a production release.

## Review checklist

- [ ] French (`fr`): molecular-biology terminology reviewed
- [ ] Korean (`ko`): molecular-biology terminology reviewed
- [ ] 中文 (`zh-Hans` internally): molecular-biology terminology reviewed
- [ ] QC warning meanings checked against the English source
- [ ] QC documentation formulae, units, thresholds, and citations checked
- [ ] Remaining module documentation (Introduction, Multiplex PCR, Overlap PCR, Mutagenesis, Workspace, Restriction, USER, Golden Gate, Gibson) reviewed
- [ ] Layout checked on desktop and mobile in all four languages

## Terminology policy

Keep product names and widely recognized laboratory tokens unchanged where conventional: PrimerWeaver, PCR, Tm, FASTA, IUPAC, Golden Gate, Gibson, USER, enzyme names, nucleotide symbols, units, DOI strings, and publication titles.

The user-facing language selector must display `English`, `Français`, `한국어`, and `中文`. The internal browser locale code must not be shown as a language name.
