入门指南

是否需要登录或付费？

不需要。PrimerWeaver 对学术和商业用途均免费。源代码依据 MIT 许可证发布。无需登录，也不使用 Cookie，符合 NAR Web Server 指南。

我的序列数据会上传或保存在服务器上吗？

不会。从引物设计到计算机模拟质量控制，所有计算均 100% 在您的本地浏览器中完成（客户端处理）。您的序列绝不会上传、传输或存储到我们的服务器，确保数据完全私密且安全。

支持哪些序列格式？

PrimerWeaver 接受 FASTA 或纯文本格式的标准 DNA 序列。经用户许可后，系统会自动移除数字、空白字符以及非 IUPAC 核苷酸/氨基酸字符。

设计参数与准确性

约束参数（Tm、GC%、发夹、二聚体）分别表示什么？

熔解温度（Tm）：50% 的引物-靶序列双链发生解链时的温度。PrimerWeaver 使用最近邻法准确计算 Tm。较高的 Tm 有利于特异性，较低的 Tm 可减少非特异性扩增。实际设计中，引物 Tm 通常设为约 55–65 °C。对于成对引物，通常建议 ΔTm 小于 5 °C，以确保退火一致。

GC 含量（%）：引物中鸟嘌呤和胞嘧啶碱基所占的百分比，典型范围为 40–60%。较高的 GC 含量会提高 Tm，但也会增加形成二级结构的风险。

最大发夹 ΔG：引物内部潜在分子内二级结构（发夹）的吉布斯自由能。数值越负，表示发夹越稳定、自退火概率越高。典型阈值为 −3 kcal/mol。

最大二聚体 ΔG：两条引物之间潜在双分子二级结构（二聚体）的吉布斯自由能。数值越负，表示引物间结合越强。典型阈值为：同源二聚体 −6 kcal/mol，异源二聚体 −8 kcal/mol。

PrimerWeaver 如何保证热力学计算的准确性？

PrimerWeaver 采用行业标准的最近邻热力学模型计算 Tm 和二级结构：

  • Tm 计算：采用最近邻法（SantaLucia，1998），使用根据实验得到的 DNA 二核苷酸步进 ΔH° 和 ΔS° 值。Tm 的计算公式为：Tm = (ΔH° − T°) / ΔS°。
  • 二级结构：基于 Watson–Crick 碱基配对和堆积相互作用估算吉布斯自由能（ΔG）。发夹和二聚体的 ΔG 值用于预测二级结构稳定性（数值越负，结构越稳定）。
  • 跨工具比较：Tm 和 ΔG 均使用已发表的最近邻参数计算；与其他平台的比较（参见有关 Tm 差异的常见问题）旨在说明不同实现所造成的差异，并非宣称本工具更准确。

注意：计算得到的 Tm 和 ΔG 仅作为引物设计参考。实际退火行为取决于缓冲液、聚合酶及实验设置；当实验性能至关重要时，请在您自己的 PCR 实验中验证。

为什么 Tm 与 SnapGene、Benchling、Multiple Primer Analyzer 或其他工具的结果不同？

我们并不声称 PrimerWeaver 比其他平台更准确。许多常用工具都采用相同的最近邻热力学框架，但由于具体实现和默认设置不同（例如一价/二价盐浓度、引物浓度），所得 Tm 值可能不同。

我们论文中的基准测试（图 2；补充表 S1）包括与 SnapGene、Benchling 和 Multiple Primer Analyzer 的比较，目的是展示这种跨平台差异，而非对工具进行排名。在 PrimerWeaver 中，用户可调整这些参数，使估算结果与自己的 PCR 条件相匹配。

实用建议：将计算得到的 Tm 视为引物设计参考，而非唯一、由实验确定的“真值”。当实验性能至关重要时，请在您自己的实验中验证退火条件。

为什么多重 PCR 分池结果与 PrimerPooler 等工具不同？

我们并不声称 PrimerWeaver 比 PrimerPooler 更准确。两种工具解决的任务不同：

  • PrimerWeaver 多重 PCR：自动完成引物设计及兼容性感知分池。分池数量由热力学约束（在设计模式下还包括片段大小/脱靶约束）决定，而非由用户手动设定。
  • PrimerPooler：将一组已有引物划分到不同池中；您可以指定所需的池数，适用于序列固定且需要达到目标反应管数量的情况。

在我们的论文中，基准测试引物由 PrimerWeaver 设计；PrimerPooler 不设计引物，而是以这些序列作为输入。与 PrimerPooler 默认“计算机建议”池数的比较仅反映其默认设置，并不代表指定池数后该工具的能力上限。

实用建议：如需集成式设计和分池建议，请使用 PrimerWeaver。若您已有引物，并需要用户指定的池数，可考虑使用 PrimerPooler。在质量控制模式下，PrimerWeaver 主要依据热力学因素对已有引物分池（不使用片段大小/脱靶规则）。

工作流程方法

限制性内切酶克隆与 Golden Gate 有何区别？

限制性内切酶克隆：使用传统 II 型限制性内切酶（例如 EcoRI、BamHI）在特定识别位点切割 DNA。引物会在插入片段上添加限制性内切酶位点，使其可被切割并连接至经相同酶切的载体。强烈建议在限制性位点两侧添加保护碱基，以确保 PCR 产物能够被高效直接酶切。连接后，限制性内切酶识别位点会保留在载体-插入片段连接处。

Golden Gate（IIS 型）：使用在识别位点外切割 DNA 的 IIS 型酶（例如 BsaI），可在单一反应中无缝、定向组装多个片段。酶识别并切割两侧的“突出端”，使片段按正确顺序自组装，同时避免再次连接。

建议：Golden Gate 更快速、更灵活，适合多片段组装；限制性内切酶克隆则更传统、成熟，适合单片段插入。

Gibson Assembly 与其他克隆方法有何区别？

Gibson Assembly 是一种等温体外组装方法，结合了以下三种酶的作用：

  • 外切核酸酶：在片段末端产生短的单链突出端（通常为 15–30 bp）。
  • DNA 聚合酶：填补外切核酸酶作用所产生的缺口。
  • DNA 连接酶：封闭切口，形成连续 DNA。

三种反应在 50°C 下于同一反应管中同时进行，因此快速而高效。PrimerWeaver 设计的引物会为每个片段添加同源突出端（默认为 25 bp）。随后，片段通过重叠区相互“识别”并按顺序组装，无需预先酶切载体或进行中间连接步骤。

什么是重叠 PCR（OE-PCR），应如何使用？

重叠 PCR（又称重叠延伸 PCR，OE-PCR）是一种无需中间载体即可组装多个 DNA 片段或引入特定突变的方法。该方法使用重叠引物，在片段之间形成兼容的突出端。

基本流程：

  1. 第 1 轮：使用外侧引物和含有重叠 3' 区域（重叠区）的内侧引物，分别扩增各片段。
  2. 第 2 轮：混合所有 PCR 产物；相互重叠的单链区域彼此退火，聚合酶沿重叠区延伸，形成全长融合产物。
  3. 第 3 轮：加入外侧引物，重新扩增全长产物以提高产量。

该方法非常适合定点突变（在片段连接处引入改变）或在结构域之间构建自定义连接肽。

多重 PCR 分池如何工作？

多重 PCR 模块首先为所有靶标设计最佳引物，然后分析引物间的潜在冲突，并将其划分到不同池中以尽量减少干扰：

系统会考虑三类冲突：

  • 交叉二聚体冲突：引物之间较强的热力学相互作用（ΔG ≤ −6 kcal/mol）可能导致形成引物二聚体，消耗引物并造成扩增失败。二聚体评分较高的引物会被分到不同池中。
  • 产物大小冲突：大小非常接近的 PCR 产物（差值 < 大小容差）在凝胶电泳中可能无法区分。产生相近大小产物的引物会被分到不同池中，以便在凝胶上分辨。
  • 脱靶扩增冲突：若多对引物可扩增同一非靶序列，会在凝胶电泳中产生重叠条带，难以识别正确产物。这类引物会被分配到不同池中。

PrimerWeaver 使用图着色算法，将引物自动分配到数量最少的兼容池中，在避免上述冲突的同时实现高效多重扩增。

如何为定点突变设计引物？

PrimerWeaver 的定点突变模块采用重叠延伸 PCR（OE-PCR）策略，设计用于引入位点特异性突变的引物。

设计方法：输入野生型序列并指定所需突变（例如 V55A：将第 55 位的缬氨酸替换为丙氨酸）。工具会设计两对位于突变位点两侧的引物。每对引物生成一个在重叠区含有所需突变的 PCR 片段。引物的设计使其含突变的 3' 端彼此互补。

关键实验步骤：

  • 第 1 轮：使用设计好的引物对，以模板分别扩增两个片段。每个片段都包含突变的一部分。
  • 第 2 轮（重叠延伸）：混合两个 PCR 产物；含突变的重叠单链区域彼此退火，聚合酶沿重叠区延伸，生成全长突变产物。
  • 第 3 轮：如有需要，使用外侧引物重新扩增全长产物，以提高产量。
  • 验证：在使用最终构建体之前，通过测序确认突变。
如何为多片段组装（USER、Golden Gate 或 Gibson）设计引物？

输入准备：提供要组装的所有 DNA 片段（例如启动子、CDS、终止子、骨架）。您可以上传或粘贴 FASTA 格式的序列。

对于 USER 克隆：

  • USER（尿嘧啶特异性切除试剂）克隆使用含尿嘧啶的引物，在 DNA 片段间形成无缝连接。
  • 指定重叠区长度（通常为 7–15 bp）。
  • PrimerWeaver 会设计在重叠区特定位置以尿嘧啶取代相应碱基的引物。
  • PCR 后，用 USER 酶混合物处理，使 DNA 在尿嘧啶位置断裂，产生互补的单链突出端。
  • 混合各片段后，互补突出端退火形成无缝组装体；通常会在转化后完成修复。

对于 Golden Gate：

  • 选择 IIS 型限制性内切酶（例如 BsaI、BsmBI）。
  • PrimerWeaver 会设计在每个片段两侧带有兼容突出端的引物。
  • PCR 后，使用所选酶建立 Golden Gate 组装反应；片段将在单一反应中按正确顺序组装。

对于 Gibson Assembly：

  • 可选：选择插入片段之间的连接序列。
  • 指定重叠区长度（通常为 20–30 bp）。
  • PrimerWeaver 在片段末端添加同源序列；各片段通过重叠区，在含 Gibson 组装预混液的单次 50°C 反应中完成组装。

    • 专业提示：同时为所有片段设计引物，以确保兼容性和最佳组装比例。

如何导出和使用结果？

PrimerWeaver 为引物设计和组装序列提供以下导出选项：

  • 引物文件（FASTA 格式）：下载为 primers.txt。文件包含所有设计好的引物序列，采用标准 FASTA 格式，每条引物对应一个条目，可直接用于向合成公司订购，或在基因组数据库中进行 BLAST 检索。
  • 组装序列：将最终组装的 DNA 序列（适用于 Golden Gate、Gibson、USER 或 OE-PCR 等组装工作流程）以 FASTA 格式下载。文件包含按正确顺序、通过兼容连接区组装的所有片段。

使用建议：

  • 将 FASTA 文件中的引物序列直接复制到引物订购表单中。
  • 开展实验前，将组装序列与设计要求进行比对核验。
  • 保存这两个文件，以便记录和复现实验设计。
  • 使用 BLAST 验证引物对目标基因组或参考序列的特异性。

质量控制与验证

如何解读引物质量控制报告中的指标？

引物质量控制模块对引物对进行计算机模拟分析，以预测潜在问题：

  • 特异性（类似 BLAST）：PrimerWeaver 在所提供的参考序列（模板）中检索，确保引物主要结合预期靶标。高特异性可减少脱靶扩增。
  • 发夹形成：预测分子内二级结构。若结构过于稳定，引物在 PCR 中可能无法正常延伸。
  • 同源二聚体形成：评估相同引物能否彼此结合；这种结合可能会占用引物，降低 PCR 效率。
  • 异源二聚体形成：检查正向与反向引物之间的交叉反应；稳定的二聚体可能降低 PCR 产量。
  • GC 钳（3' 端）：理想情况下，引物 3′ 端以 G 或 C 结尾，这有助于提高引物-模板稳定性及延伸效率。PrimerWeaver 会标记以 A 或 T 结尾的引物，因为在某些 PCR 条件下其效率可能较低。
  • 同聚物连续序列：连续 4 个或更多相同碱基（例如“AAAA”）会被标记，因为这类序列会降低特异性，并可能在扩增过程中促进错误引发或滑移。

解读建议：请仔细检查警告，尤其是在重复序列或低复杂度区域中进行设计时。

如何验证所设计的引物能否在实验中正常工作？

订购引物前，请遵循以下最佳实践：

  • 计算机模拟质量控制：使用 PrimerWeaver 的质量控制模块检查发夹、二聚体和脱靶结合，并审查所有警告。
  • BLAST 检查：将正向和反向引物序列复制到 NCBI BLAST，验证它们与靶标高度特异性匹配（e-value < 0.01）。
  • Tm 差异：确保正向和反向引物的 Tm 相差不超过 3–5°C，以实现均衡的 PCR 扩增。
  • 多重性检查：在多重 PCR 设计中，运行 PrimerWeaver 的二聚体分析，并遵循建议的分池方案。
  • 实验优化：订购引物后，采用梯度 PCR（退火温度 58–62°C）确定最佳温度，并根据需要调整。

提示：若引物失效，请检查质量控制报告和模板质量，并考虑放宽约束后重新设计。

引物设计失败，常见原因有哪些？

设计失败可能由多种原因造成，通常与约束条件有关：

  • 未找到有效引物：工具无法找到满足所有约束条件（例如 Tm、GC%、产物大小）的引物对。请尝试扩大 Tm 范围。
  • 低复杂度区域：在复杂度极低的区域（例如“AAAAAAAAAA”）无法设计引物。请考虑调整靶区域或移除模糊碱基。
  • 二聚体评分过高：在多重 PCR 模式下，若某条引物不可避免地与所有其他引物形成高亲和力二聚体，则可能被排除。请尝试减少靶标数量或提高二聚体阈值。
  • 模板问题：请确认模板序列正确，且长度足以覆盖靶区域两侧（通常各需约 50 bp）。
如果第一组引物失效，可以重新设计吗？

可以！如果设计的引物在实验中无法正常工作：

  1. 检查质量控制报告：查看发夹、二聚体或脱靶结合预测。
  2. 放宽约束：尝试扩大 Tm 范围（例如使用 55–65°C，而不是 62–65°C）。
  3. 核验模板 DNA：确保 PCR 模板纯净且浓度适宜（标准 50ul 反应中，基因组 DNA 通常为 100–1000 ng，质粒通常为 1–20 ng）。
  4. 检查试剂：确认聚合酶活性、dNTP 新鲜度及引物储存条件。
  5. 优化 PCR 条件：测试多个退火温度（梯度 PCR）和延伸时间。
  6. 使用 PrimerWeaver 重新设计：可沿用原约束条件，或根据失败原因进行调整。PrimerWeaver 通常会返回多组引物对；若首选方案失败，备选方案可能有效。

做好记录：记录有效的引物组和实验条件，有助于今后的设计。

技术细节与支持

PrimerWeaver 支持哪些参考序列格式和大小？

PrimerWeaver 针对常见分子生物学工作流程进行了优化，支持：

  • 序列格式：FASTA（多序列或单序列）、DNA 纯文本（大小写均可，忽略空白字符）。
  • 典型大小范围：100 bp 至数十万碱基（主要受浏览器性能限制，目前文件大小上限为 1MB）。
  • 蛋白质序列：不直接支持；请先翻译为 DNA（未内置密码子使用偏好优化，但您可以手动优化）。
计算要求和浏览器兼容性如何？

浏览器兼容性：PrimerWeaver 可在任何启用 JavaScript 的现代浏览器中运行：

  • Chrome 60+（推荐，可获得最佳性能）
  • Firefox 55+
  • Safari 12+
  • Edge 79+

性能建议：

  • 计算主要受 CPU 性能限制；对于大型设计（>100 个片段），旧设备或移动设备可能需要更长时间。
  • 关闭其他标签页或应用程序，以释放 CPU 资源。
  • 使用最新版本的浏览器，以获得最佳优化效果。

运行缓慢故障排除：若设计耗时 >30 秒，请简化输入（减少片段数量、缩短序列）后重试。

进行多个设计时的替代方案：
